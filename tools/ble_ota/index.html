使用步骤
  1. 设备开机，确认屏幕右上角蓝牙已启动（设备名 ESP32-S3-AI）。
  2. 点「连接设备」，在弹窗里选择 ESP32-S3-AI。
  3. 选择 firmware.bin，点「开始升级」，等待进度到 100%。
  4. 设备会自动重启；若没有，手动按一下 RESET。升级期间不要关闭页面。

若页面无法打开蓝牙：请用 http://localhost 访问，或使用支持 Web Bluetooth 的浏览器。

填好设备 IP 点「加载设置」走 HTTP；设备没连 WiFi 时保持蓝牙连接即可（自动走蓝牙通道），表单由固件配置表自动生成。
蓝牙模块（BT04E）配置

通过设备背后的 AT 串口直配 BT04E。注意：AT 命令仅在模块无蓝牙连接时有效；改参数后固件会自动补发 AT+RESET。

先点「测试连接」，通了再查信息。
AT 口调试（GPIO41 TX / GPIO42 RX）

用 USB-TTL 把电脑串口助手接到设备：适配器 RXD→41、TXD→42、共地。 打开调试口后，这里发出的字节从 41 出去、42 收到的字节回显在下方——双向都通说明串口链路正常（与 BT04E 无关的裸测）。调试期间 AT 命令不可用。
